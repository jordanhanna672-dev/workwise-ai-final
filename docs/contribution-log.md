## Notes on filling this in honestly

- The "Areas owned" lines above are *suggestions* based on each person's
  stated role, not a record of actual commits — nobody involved in
  writing this log has access to your real git history, so these are a
  reasonable starting guess to edit against reality, not a claim of fact.
- Commit *count* is a weak signal on its own — a single large, well-tested
  PR can represent more real work than ten tiny commits. Use the log to
  jog memory, then describe actual contributions in your own words.
- If someone contributed significantly to design/planning/testing that
  doesn't show up as commits (e.g., the accuracy dataset's expected
  labels, UX decisions, QA passes), say so explicitly — the commit log
  alone won't capture it.
